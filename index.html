G*Power 3.1 Simulator (A Priori)

Estimasi perkiraan besar sampel menggunakan simulasi algoritma G*Power untuk uji statistik T-tests: Means: Difference between two independent means.

  • Tail(s): Pilih Two (Dua arah) karena Anda mencari "Perbedaan".
  • Effect size d: Ukuran kekuatan perbedaan secara klinis (Cohen's d). Default standar 0.5.
  • α err prob (Alpha): Tingkat batas kemaknaan. Default 0.05 (95%).
  • Power (1-β err prob): Probabilitas menolak H0 yang salah. Minimal klinis 0.80 (80%).
  • Allocation ratio: Rasio perbandingan sampel Grup 1 dan 2. Isi 1 jika seimbang.
